# What's Changed
---
FieldWeave now has a changelog! It will display after every update, if you miss it and want to view it again, you can do so in the about page in the settings by pressing the view changelog button. In addition, it now has released based updates, this allows there to be a changelog that can be viewed ahead of time. The most notable change in this update is the addition of the measurement tab allowing you to measure things in FieldWeave. This also includes manual DPI calibration built in so you no longer have to go to an external program to obtain the DPI of a given image. 

In the next major update, you can look forward to an overhaul of the focus stacking allowing you to use other programs, improvements to time estimates, and the long awaited built in image stitching for tree core samples. 

If you come across any bugs while using FieldWeave, have feedback, or just want to request new features, please send them to <contact@FieldWeave.com> or open an issue on Github at <https://github.com/AnthonyvW/FieldWeave/issues/new>

# New Features & Improvements
---
- Added patch number to versioning scheme
- Added patch notes pop up
- Added button to view patch notes in the about page in settings
- Can now use the arrow keys to navigate when zoomed in
- Focus stacked images now preserve image metadata
- Added Measurement Tab
    - Added image viewer capable of handling terapixel images
    - Added manual DPI calibration
    - Added 34 measurement types
    - Added 4 annotation options
- Added manual DPI calibration path in the DPI calibration tab. This is also now a fallback in case the automatic DPI calibration fails.
- Added way to cancel the DPI calibration and return to the calibration tab from the DPI calibration tab.
- Added way to cancel the camera space calibration and return to the calibration tab from the camera space calibration tab.
- If the DPI calibration routine or the automatic DPI calibration fails, it will no longer set the DPI.
- All automation routines now have a button to open the output folder when running.
- Added github link on about page.
- Switched to release based updates

# Bugfixes
---
- Version field in config files now successfully migrates and is saved
- Fixed the post processing manager creating a redundant config
- While developing it will no longer warn about failing to update.
- Toasts no longer throw errors if you close the program while one is active.
- Fixed Amscope cameras not saving all camera metadata.
- Fixed Tiff writer not saving metadata.
- Camera metadata now saves to the proper metadata fields.
- Fixed issue where occasionally when doing area scan imaging an image from the previous stack would end up in the next stack.

# Known bugs
---
- Automatic camera calibration fails when using a resolution of 5120x3840
- Automatic DPI calibration fails if slide isn't perfectly straight
- Automatic DPI calibration tends to fail when using high resolution imagery
- Logs tab becomes extremely laggy on long runs.
