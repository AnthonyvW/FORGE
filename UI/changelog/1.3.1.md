# Bugfixes
---
- Load Image in the measurements tab no longer consumes multiple gigabytes of ram when opening images with pyramids
- Improved image loading speeds when using the load image.

# Known bugs
---
- Automatic camera calibration fails when using a resolution of 5120x3840
- Automatic DPI calibration fails if slide isn't perfectly straight
- Automatic DPI calibration tends to fail when using high resolution imagery
- Logs tab becomes extremely laggy on long runs.
